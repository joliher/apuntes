# 🔎 SOC II — Service Organization Control Type II

El **SOC II** es un tipo de **informe de auditoría de seguridad** diseñado para organizaciones que prestan servicios tecnológicos o procesan datos de terceros (proveedores SaaS, centros de datos, proveedores cloud, etc.).

---

## 📌 Definición y Origen

| Elemento | Detalle |
| :--- | :--- |
| **Emitido por** | Un **CPA** (*Certified Public Accountant*, auditor certificado) acreditado |
| **Según los criterios de** | **AICPA** (*American Institute of Certified Public Accountants*) |
| **Ámbito** | Internacional, aunque de origen estadounidense |
| **Obligatoriedad** | ❌ Voluntario — pero frecuentemente exigido contractualmente por los clientes |

---

## 🏛️ Trust Service Criteria (TSC)

El SOC II evalúa los controles de seguridad de una organización en base a los **Trust Service Criteria** (Criterios de Servicios de Confianza):

| Criterio | Descripción |
| :--- | :--- |
| **Seguridad** *(obligatorio)* | Protección del sistema frente a accesos no autorizados (lógicos y físicos) |
| **Disponibilidad** | El sistema está disponible para operar según lo acordado |
| **Integridad del procesamiento** | El procesamiento del sistema es completo, válido, preciso y oportuno |
| **Confidencialidad** | La información designada como confidencial se protege adecuadamente |
| **Privacidad** | La información personal se recopila, usa, retiene y divulga conforme a la política de privacidad |

> 💡 El criterio de **Seguridad** es el único obligatorio. Los demás se incluyen según la naturaleza del servicio prestado.

---

## 🆚 SOC I vs SOC II vs SOC III

| Informe | Enfoque | Audiencia |
| :--- | :--- | :--- |
| **SOC I** | Controles relevantes para los informes financieros de los clientes | Auditores financieros |
| **SOC II** | Controles de seguridad, disponibilidad y privacidad del sistema | Clientes, socios y reguladores (uso restringido) |
| **SOC III** | Versión resumida y pública del SOC II | Público general |
